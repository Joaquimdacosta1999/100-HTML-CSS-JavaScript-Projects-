# 🚀 100 HTML, CSS & JavaScript Projects

Welcome to the ultimate frontend playground! This repository is a comprehensive collection of **100 unique web projects** built entirely with vanilla **HTML5**, **CSS3**, and **JavaScript (ES6+)**. 

Whether you are a beginner looking to get your hands dirty or an intermediate developer wanting to sharpen your problem-solving skills, this repository is designed to help you master the core fundamentals of web development.

## 🛠️ Tech Stack & Concepts Covered
* **HTML5:** Semantic markup, forms, audio/video integration, and accessible structures.
* **CSS3:** Flexbox, Grid, custom animations, transitions, responsive media queries, and glassmorphism.
* **Vanilla JavaScript:** DOM manipulation, Event listeners, Fetch API/Async-Await, LocalStorage, and game logic.

## 📁 Repository Structure
Each project is fully self-contained within its own directory for easy, distraction-free browsing:
```text
├── 01-Quiz-Game
│   ├── index.html
│   ├── style.css
│   └── script.js
├── 02-weather-dashboard/
├── ...
└── 100-interactive-game/
```

## 💡 Why Build 100 Projects?
* **Build Muscle Memory:** Writing pure HTML, CSS, and JS reinforces core web concepts better than relying on frameworks too early.
* **Portfolio Ready:** You will finish with 100 distinct elements, components, and applications to showcase to potential employers.
* **100 Days of Code:** An ideal companion repository if you are taking on the #100DaysOfCode challenge.
